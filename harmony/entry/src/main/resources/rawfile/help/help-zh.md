# Mirobody 使用帮助

你好。我是 **Mirobody**,一个把你的健康数据和一个语言模型放在**同一台设备**上的助手。

这份文档本身就是一条模型回复 —— 它用到的每一种排版,都是你在真实对话里会看到的。所以它顺带也是一次渲染自检:如果下面有哪块显示不对,那就是个 bug,欢迎反馈。

---

## 一、先跑起来

发消息之前需要选一个模型。点输入框上方那个模型名就能切换。

1. **本地模型** —— 一个 `.gguf` 文件,完全在这台设备上跑
   1. 从"添加模型"里选中文件,它会留在你自己的目录里,我们不复制
   2. 首轮加载要几秒,之后就常驻内存了
2. **云端模型** —— 你自己的 API Key,直连服务商
   1. 在密钥管理里填 Key 和 `baseUrl`
   2. Key 存在设备的密钥库里,不经过我们的服务器 —— 我们没有服务器

> 两条通路的区别不是速度,是**数据去了哪里**。本地模型下,你的健康数据一个字节都不出设备。

### 怎么选

| 场景 | 建议 | 联网 | 数据外流 |
|:--|:--|:--:|:--:|
| 问自己的化验单 | 本地 | 否 | 无 |
| 长文写作、复杂推理 | 云端 | 是 | 有 |
| 飞机上、信号差 | 本地 | 否 | 无 |

## 二、我能读到什么

打开健康数据授权后,我可以读到华为运动健康里的这些指标:

- [x] 步数、静息心率、心率
- [x] 睡眠时长与分期
- [ ] 血糖、血压 *(授权通过后开放)*
- [ ] 体温

没授权之前,这一块是**完全空的** —— 不是读了不说,是根本没读。

### 3.4 公式

该用公式的时候我会用。比如体质指数 $BMI = w / h^2$,其中 $w$ 是体重(kg)、$h$ 是身高(m);估算肾小球滤过率用的 CKD-EPI 则要长一些:

$$
eGFR = 142 \times \min(S_{cr}/\kappa, 1)^{\alpha} \times \max(S_{cr}/\kappa, 1)^{-1.200} \times 0.9938^{age}
$$

血钠 ($Na^+$)、血钾 ($K^+$)、血钙 ($Ca^{2+}$) 这类离子写在句子里也是一样的。

### 3.5 代码

问到技术问题,代码会单独成块,可以左右滑动:

```python
def bmi(weight_kg: float, height_m: float) -> float:
    """体质指数。身高用米,不是厘米。"""
    return weight_kg / (height_m ** 2)
```

行内的 `变量名`、`config.yml` 这类也会用等宽字体标出来。

## 四、可以直接输入的命令

在输入框里打一个 `/`,会弹出可用命令的列表,边打边收窄,点一下就执行 —— **不用记**。

| 命令 | 作用 |
|:--|:--|
| `/help` | 显示这份文档 |
| `/new` | 开始新对话 |
| `/incognito` | 开关隐私模式,本轮不写入历史 |

这几件事菜单里**也都有**。命令行只是给顺手的人的捷径,不是必须学会的语法。

命令**不会**发给模型,不占用对话上下文,也不写进历史记录 —— 包括你打的那行 `/help` 本身。

## 五、隐私

这一节不是免责声明,是事实描述。

1. **本地模型**:提问、健康数据、回答,全部在设备内完成
2. **云端模型**:你的提问会发给你自己配置的那家服务商 —— 是你的账号,不是我们的
3. **无痕模式**:开启后这轮对话不写入历史记录
4. 我们**没有**服务器,所以谈不上"上传到我们这里"

> **注意**:我不是医生。我能帮你读懂指标、发现趋势、准备就诊时要问的问题,但**不能**替代诊断。指标异常请找医生。
