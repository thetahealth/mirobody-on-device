# Mirobody 使用帮助

你好。我是 **Mirobody**,一个读你的健康数据、并就此回答问题的助手;模型也可以就跑在**这台手机**上,而不是别的什么地方。

这份文档本身就是一条模型回复 —— 它用到的每一种排版,都是你在真实对话里会看到的。所以它顺带也是一次渲染自检:如果下面有哪块显示不对,那就是个 bug,欢迎反馈。

---

## 一、先跑起来

发消息之前需要选一个模型。点输入框下方那个模型名就能切换。

1. **本地模型** —— 一个 `.litertlm` 文件,完全在这台设备上跑
   1. 在模型管理里下载一个,或者导入你已经有的文件
   2. 首轮加载要几秒,之后就常驻内存了
   3. 它只凭对话本身回答:没有工具,读不到健康数据,也不联网
2. **服务端模型** —— 你登录的那台 Mirobody 服务器提供的那些模型
   1. 只有这条通路带工具,所以也只有它能读你的健康数据、打开你发的附件、画图表
   2. 你的提问先到那台服务器,再由它发给所配置的服务商

> 两条通路的区别不是速度,是**答案是拿什么拼出来的**。本地这条一个字节都不出这台手机 —— 同时它也读不到你的任何一项指标。

### 怎么选

| 场景 | 建议 | 联网 | 数据外流 |
|:--|:--|:--:|:--:|
| 问自己的化验单 | 服务端 | 是 | 有 |
| 长文写作、复杂推理 | 服务端 | 是 | 有 |
| 飞机上、或者不想让它出这台手机 | 本地 | 否 | 无 |

## 二、我能读到什么

打开健康数据授权后,我可以通过"健康连接"(Health Connect)读到这些指标:

- 步数
- 心率
- 睡眠记录
- 体重

血糖、血压、体温**还不在**其中 —— App 根本没有申请这几项权限,所以也谈不上"读了不给你看"。

没授权之前,这一块是**完全空的** —— 不是读了不说,是根本没读。

### 3.4 公式

该用公式的时候我会用。比如体质指数 $BMI = w / h^2$,其中 $w$ 是体重(kg)、$h$ 是身高(m);估算肾小球滤过率用的 CKD-EPI 则要长一些:

$$
eGFR = 142 \times \min(S_{cr}/\kappa, 1)^{\alpha} \times \max(S_{cr}/\kappa, 1)^{-1.200} \times 0.9938^{age}
$$

血钠 ($Na^+$)、血钾 ($K^+$)、血钙 ($Ca^{2+}$) 这类离子写在句子里也是一样的。

美元符号同时也是货币符号,所以不会一见到就当公式:一项 $100 的检查和一项 $200 的检查,这行会原样显示成文字。

### 3.5 代码

问到技术问题,代码会单独成块:

```python
def bmi(weight_kg: float, height_m: float) -> float:
    """体质指数。身高用米,不是厘米。"""
    return weight_kg / (height_m ** 2)
```

行内的 `变量名`、`config.yml` 这类也会用等宽字体标出来。

## 四、可以直接输入的命令

在输入框里打一个 `/`,会弹出可用命令的列表,边打边收窄,点一下就执行 —— **不用记**。

| 命令 | 作用 |
|:--|:--|
| `/help` | 显示这份文档 |
| `/new` | 开始新对话 |
| `/incognito` | 开关隐私模式,本轮不写入历史 |

这几件事菜单里**也都有**。命令行只是给顺手的人的捷径,不是必须学会的语法。

命令**不会**发给模型,不占用对话上下文,也不写进历史记录 —— 包括你打的那行 `/help` 本身。

## 五、隐私

这一节不是免责声明,是事实描述。

1. **本地模型**:提问和回答都在这台手机上完成,它本来也读不到任何数据
2. **服务端模型**:提问、回答用到的健康数据、以及回答本身,都存在你登录的那台服务器上、挂在你的账号下 —— 正因如此你之后才能翻回这段对话
3. **无痕模式**:开启后这轮对话不写入历史记录
4. 我写出来的链接只会用 `http`、`https`、`mailto` 打开 —— 模型无权决定你的手机启动哪个 App

> **注意**:我不是医生。我能帮你读懂指标、发现趋势、准备就诊时要问的问题,但**不能**替代诊断。指标异常请找医生。
